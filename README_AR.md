# مُعلِّم AI — النسخة الأولية (MVP)

هذه بداية عملية لمشروع منصة تحوّل كتب PDF إلى دورات تعليمية قابلة للتوسع.

## ما الذي يعمل في هذه النسخة؟
- واجهة عربية RTL لاختيار ملف PDF.
- واجهة API باستخدام FastAPI لاستقبال ملف PDF.
- استخراج النص من ملفات PDF النصية باستخدام PyMuPDF.
- تقسيم النص المستخرج إلى مقاطع مع أرقام الصفحات.
- نقطة API لتوليد درس تجريبي من النص المستخرج.
- هيكل قابل لتوصيل مزود ذكاء اصطناعي لاحقًا.

## ما الذي لا يزال يحتاج إلى إعداد؟
- مفتاح API من مزود الذكاء الاصطناعي.
- OCR للكتب الممسوحة ضوئيًا.
- قاعدة بيانات وحسابات مستخدمين.
- مراجعة علمية متخصصة قبل نشر الدروس.

## التشغيل محليًا
يتطلب Python 3.11 أو أحدث.

1. افتح مجلد `backend`.
2. أنشئ بيئة افتراضية:
   `python -m venv .venv`
3. فعّل البيئة الافتراضية.
4. ثبّت المتطلبات:
   `pip install -r requirements.txt`
5. شغّل الخادم:
   `uvicorn main:app --reload`
6. افتح `frontend/index.html` في المتصفح.

عنوان API الافتراضي:
`http://127.0.0.1:8000`

## ملاحظات مهمة
- لا ترفع كتبًا لا تملك حق استخدامها أو معالجتها.
- النص المستخرج ليس ضمانًا لصحة OCR أو سلامة ترتيب الصفحات.
- لا تنشر درسًا مولدًا آليًا قبل التحقق من مطابقته للمصدر ودقته العلمية.
- في هذه النسخة، توليد الدرس التجريبي يستخدم قواعد بسيطة ولا يستدعي نموذجًا مدفوعًا. توصيل API خطوة تالية مستقلة.
